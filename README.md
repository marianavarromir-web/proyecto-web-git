\# Mi Proyecto Web



Sitio web sencillo hecho solo con HTML para practicar Git, GitHub, ramas y Pull Requests.



\## Tabla de contenido

\- \[Instalación](#instalación)

\- \[Estructura](#estructura)

\- \[Mejoras implementadas](#mejoras-implementadas)

\- \[Flujo de trabajo](#flujo-de-trabajo)



\## Instalación

1\. Clona el repositorio:

&#x20;  `git clone https://github.com/marianavarromir-web/proyecto-web-git.git`

2\. Abre `index.html` en cualquier navegador.



\## Estructura

\- `index.html`: página principal del sitio.

\- `.gitignore`: excluye la carpeta `.vscode/` y archivos del sistema.

\- `README.md`: documentación del proyecto.



\## Mejoras implementadas

1\. \*\*Menú de navegación\*\* (`feature/menu`): enlaces internos a las secciones Inicio, Horario y Contacto.

2\. \*\*Tabla de horario\*\* (`feature/tabla`): tabla con el horario de clases.



\## Flujo de trabajo

Cada mejora se hizo en su propia rama, se subió a GitHub y se fusionó con `main` mediante un Pull Request.
